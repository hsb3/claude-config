Rule (2026-11-09): `.claude/memory/` is committed; the whole repo is a statement of preferences, so memories belong in it. Write every memory impersonally: state the rule or fact, its date, the why and how to apply it. No personal names, email addresses, machine paths outside the repo, or anything a public reader should not see.

**Why:** the repo is public (github.com/hsb3/claude-config). Memory that reads like a private note about a person does not belong there; memory that reads like a convention does.

**How to apply:** before saving a memory, reread it as a stranger would. Replace "the user asked" with "Rule (date):" and "their setup" with "this repo". The same standard applies when updating older memories. Related: [[consult-claude-code-docs-first]].
